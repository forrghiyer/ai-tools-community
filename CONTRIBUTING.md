# Contributing

Thank you for helping improve the AI Tools Community directory.

## What you can contribute

- Add a useful AI tool
- Correct outdated information
- Suggest a better category or description
- Report a broken or changed link
- Improve documentation or the project structure

## Adding a tool

Please include:

1. Tool name
2. Category
3. Official website
4. Short factual description
5. Optional: primary use case and platform

## Pull requests

Keep each pull request focused. Do not add promotional claims, affiliate links, spam, or tools that you cannot verify.

Before submitting, check that the official URL works and that the information is reasonably current.
