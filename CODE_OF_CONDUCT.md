# Code of Conduct

We want this project to be a respectful and useful open-source community.

## Expected behavior

- Be respectful and constructive.
- Focus feedback on the work, not the person.
- Welcome different experience levels and perspectives.
- Keep discussions relevant to the project.

## Unacceptable behavior

Harassment, discrimination, personal attacks, spam, malicious content, and deliberately misleading submissions are not acceptable.

Project maintainers may remove contributions or restrict participation when necessary to keep the community healthy.
